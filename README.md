# Email Automation - Task 1

This is a simple bulk email sender I made using Python.

### What it does:
- Send same email to multiple people at once
- Made GUI using Tkinter so it's easy to use
- Shows which emails were sent successfully and which failed
- Added 2 second delay so Gmail doesn't block
- If one email is wrong, program doesn't crash

### How to use:
1. First make App Password in your Gmail account
2. Run the file: python email_sender_gui.py  
3. Enter your Gmail and App Password
4. Write subject and message
5. Paste all emails (one email per line) and click Start Sending

### Files:
email_sender_gui.py - main program file

### Made with:
Python, Tkinter

Note: Don't send too many emails at once. Test with 5-10 emails first.
